# CDU-100 Refinery Digital Twin (POC)

A FastAPI web app with a live 3D digital twin of a (fictional) crude distillation unit and an AI assistant (LangGraph).

## How to run — one step
Double-click **`START.bat`**. The first run takes a few minutes (it creates `.venv` and installs packages);
after that it starts in seconds. Your browser opens **http://localhost:8000**. Close the black window to stop.

## What you see
| Area | What it does |
|---|---|
| Left list | Every asset with a status dot and health %. Click to fly the camera to it. |
| 3D view | Drag to orbit, right-drag to pan, scroll to zoom. Camera presets at the top, "Labels: smart/all/none" to declutter. Coloured ring under each asset = status; problem assets glow and pulse. |
| Asset tab | Health, remaining useful life, anomaly score, live charts (with ISO 10816 limits for pumps), all sensors, and "Simulate fault" buttons (simulation only). |
| Assistant tab | Ask in plain English: *"Which assets need attention?"*, *"Diagnose P-101A"*, *"What happens if E-102 fouls? Simulate it"*. It calls plant tools, never invents numbers, and moves the 3D camera to what it is talking about. |
| Events tab | WARN / ALARM / TRIP history. |
| `/docs` | Interactive REST API (Swagger) — useful for integration. |

The built-in scenario: pump **P-101A** has slowly developing bearing wear. Over ~15 minutes (at ×300) it goes
WARN → ALARM → TRIP and the spare **P-101B** auto-starts. Use ×1200 / ×3600 in the header to speed up, "Reset sim" to restart.

## The AI assistant (LLM)
Configured in `.env` (copied from `.env.example` on first run). Default `LLM_PROVIDER=auto`:
1. **Ollama** (local, free) if running — currently picks your installed model automatically. Best results with a
   tool-calling model: `ollama pull qwen2.5:7b`, then set `OLLAMA_MODEL=qwen2.5:7b`.
2. Else **Anthropic** (`ANTHROPIC_API_KEY`) or **OpenAI** (`OPENAI_API_KEY`).
3. Else **offline mode** — answers straight from plant data without an LLM.

## Project layout
| Folder | Purpose | Do I need to touch it? |
|---|---|---|
| `app/` | FastAPI app: `main.py` (API + WebSocket), `twin.py` (simulation loop + history), `agent.py` (LangGraph agent + tools), `llm.py` (provider choice) | This is where you develop |
| `web/` | Browser UI: `index.html`, `style.css`, `app.js` (Three.js 3D view, panels, chat) | This is where you develop |
| `backend/simulator.py` | Physics-style equipment models (pumps, exchangers, furnace, column, tanks) | When adding equipment behaviour |
| `config/` | `plant_layout.json` (equipment, tags, positions), `materials.json` (colours) | To add/move equipment |
| `Content_Source/` | 3D models + 2K textures generated by Blender (`Web/*.glb` used by the browser) | No — generated |
| `blender/` | Script that builds all 3D models procedurally | Only to change 3D models (`scripts\1_build_assets_blender.bat`) |
| `unreal/`, `scripts/2_*`, `scripts/3_*` | Optional Unreal Engine 5 version of the twin (cinematic) | No — optional, parked |
| `data/` | Telemetry CSV logs for training ML models | Input for the ML step |
