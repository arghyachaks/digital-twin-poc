Pump physics with vibration spectrum + ML training dataset

- backend/pump_physics.py: shared pump model (1x, 2x, axial, BPFO band,
  HF envelope, broadband, temps, pressures) with imbalance,
  misalignment, bearing_fault and cavitation fault modes
- Live twin uses the same physics; averaged vibration for ISO alarms
- Rule-based vibration diagnosis replaces reading the injected fault
- ml/generate_dataset.py: 400 run-to-failure pump histories with
  fault label, severity and RUL, split by pump; dataset card + plots
- UI: new sensors, fault buttons and HF envelope chart
